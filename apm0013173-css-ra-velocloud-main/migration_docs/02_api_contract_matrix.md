# API contract matrix

Source of truth: original `api/urls.py`, `api/views.py`, `api/serializers.py`, `velocloud_app/settings.py`. 46 business routes. All views declare `permission_classes = []`; default token authentication still executes. Each supports POST and DRF OPTIONS; GET/HEAD/PUT/PATCH/DELETE return method errors after authentication/content negotiation. Every application route has executed differential validation and OPTIONS comparisons. Successful business execution is assessed separately; these checks do not constitute 46 successful workflows.

Paths are case-sensitive and listed exactly. Internal prefix is `/api/`; deployed external prefix is `/svc/velocloud/api/` (`chart/values.yaml`). No trailing slash is added to the 45 slashless business routes. `/api/mds` may append a slash under CommonMiddleware; POST redirects differ by DEBUG.

All requests: JSON, form, multipart parsers; generic serializer drops undeclared fields. Business credentials: `X-username`, `X-password`, `X-url`, `X-tenant-id` via `api/utils.py:get_credentials`. Mds uses body credentials. HWStats unwraps a `data` object. Token errors run before parsing. Response bodies/status and error handling live in the referenced unchanged post methods.
